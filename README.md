# 💸 Expense Tracker AI

An AI-powered Expense Tracking App built using Android and Firebase.
The app helps users manage daily expenses, categorize spending, and track financial activity in a simple and clean way.

This project focuses on combining mobile development, real-time database handling, and intelligent expense organization into one complete system.

## 📦 Technologies

- `Java`
- `Android Studio`
- `Firebase Authentication`
- `Firebase Realtime Database / Firestore`
- `RecyclerView`
- `XML`
- `Material UI`
- `AI Logic`
- `Date & Time Handling`

## 🦄 Features

Here’s what you can do with Expense Tracker AI:

- Add Expenses :
Users can add daily expenses with amount and details.

- Expense Tracking :
All expenses are stored and displayed in a structured list.
 
- AI Spending Insights :
The app analyzes spending patterns and highlights high-expense categories.

- Smart Categorization :
Expenses are categorized

- Clean UI :
Simple and minimal interface for better usability.

- Real-Time Sync :
Data is stored in Firebase and synced instantly.

- Authentication :
User login/signup system.

## 🎯 How It Works

1. User enters expense details.
2. Data is processed and stored in Firebase.
3. Expenses are fetched in real-time.
4. RecyclerView displays data dynamically.
5. AI logic categorizes expenses.
